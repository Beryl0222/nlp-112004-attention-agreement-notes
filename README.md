# 专注计划中的自然语言委托与例外

用户在本机编写周计划并同离线演练计时器交换记录。时间使用带偏移的 ISO 8601，活动区间含开始时刻、不含结束时刻。计时器保存观察事实，用户对目的或计划的后续解释单独留档。应用名、活动和人物均为虚构。

## 本地资料

全部为 UTF-8 编码的合成业务资料。`data/contract.json` 中的列类型带 `?` 时可以是 JSON null。每组记录的 `id` 在该组中唯一，跨组关系以字段说明和清单的 `links` 为准。文字字段保留来源原句，嵌套对象按表中现有格式记录。

- `data/activities.json`。用户自定的活动和本地别称。possiblePurposes 由用户维护，用于回问。
- `data/pools.json`。确认过的共享配额。memberActivity 为用户加入此池的活动，dayBoundary 可由用户跨日设定。
- `data/notes.json`。个人手记和针对某次提醒的原话。respondsTo 为用户明确点名的另一条手记。
- `data/timeline.json`。计时器收到的窗口事实，window 同一时段可不同。hint 原样保留，不代表确认用途。
- `data/clarifications.json`。用户对活动事实的补记。entry 可引用某窗的记录，再通过原话限定其中一段。
- `data/reminders.json`。计时器以前确实显示过的提醒，保留原样作回放。

## 使用约定

个人手记可在本机导入，时钟和提醒记录都引用演练用的时间，不依赖设备的当前时刻。「本人」表示计划所有者，其他来源的句子可被本人引用。已确认的配额上限按当地日界重置，池与池之间独立，未纳入池的活动不消耗它。活动在同一池里出现于多个窗口时按时间并集记。收到活动补记只更正实际用途及相关余额，不回写当时已显示的提醒。

## 读取与检查

使用 Node.js 22.23.4，依赖仅用 Node.js 标准库。资料检查依次读入各组 JSON，检查列类型、组内编号及已登记的组间引用，并列出各组记录数。读取入口为 `tools/materials.mjs`，可单独读取一组记录，或读取整个已登记资料包。

```sh
npm run check-data
npm test
```

## 本地助手

在只读资料包之上构建的本地助手，全部代码仅用 Node.js 标准库，不联网、不写入 `data/`；用户确认结果只保存在 `state/assistant-state.json`（已在 `.gitignore`）。它只处理本人写下的计划、计时器事实与自定活动分类，不就笔记文字作任何医学判断。

### 分层（`tools/lib/`）

- `time.mjs`：带偏移 ISO、半开区间、04:00 日界切分、同池时间并集（重叠不扣两遍）。
- `catalog.mjs`：应用名/别称/词根匹配；用途→计费池映射。只有与池标签同名的用途（随手看）和显式本地别名（放松→短休）计费；等快递、联系家人、作业、查资料不自动扣池。
- `interpreter.mjs`：把手记拆成带出处的提案（限制/锁闭/锁闭豁免/短期例外/替代动作/用途声明/澄清/他人转述/拒绝/未归类）。他人“说/建议”只生成报告，本人未采纳不生效；含混项必须先澄清，澄清沿 `respondsTo` 回填。
- `plan.mjs`：确认提案为生效约定。明确例外只在自身时间、活动、用途范围内盖过一般限制；多条约定冲突且无明确例外时返回 `undecidable`，交本人选择，当次不扣配额、不断言违规。一次性例外完成即止，不自动延期。
- `adjudication.mjs`：窗口事实 + 补记切成片段。一个片段有多种合理用途且影响扣时/提示时标 `pending`，保留区间日后补判；hint 只作线索不代表确认。
- `ledger.mjs`：按池按配额日并集扣时；待确认与例外片段不扣；已显示提醒原样保留，仅事后标注其余额依据是否失效，依据错误余额发出的许可后续不可沿用。
- `review.mjs`：提醒溯源到具体手记与活动片段、一次性约定的改写建议（须本人确认才生效）、医学用语拦截。
- `assistant.mjs` / `state.mjs`：流水线门面与本机状态。

### 演示与测试

```sh
npm run demo            # explain|plan|adjudicate|ledger|reminders|review|all
npm test                # 资料检查 + 28 条单元测试
```

### 演练数据上的关键结论

- 同伴“十点全锁”是转述、本人明确未同意，不进入生效计划。
- 老师录屏例外为一次性、窗口当日 18:00–19:00；窗口结束后即使再标注“老师指定”也不延长。
- 随手看池 2026-11-20 实际并集扣时 28/20 分钟、超 8 分钟；r2、r3 两条历史提醒原样留存，但余额依据经补判失效，后续同池活动不得沿用。
- 跨 04:00 日界的短休被切成 11-20 与 11-21 各 4 分钟，分属两个配额日。
